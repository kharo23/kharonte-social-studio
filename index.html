Kharonte Social Studio

A personal desktop tool of Kharonte Studio for posting its own videos to its own TikTok account.

Kharonte Studio is an independent app developer. It builds and publishes small mobile apps and the website kharonte.dev. Kharonte Social Studio is the internal tool the studio uses to send promotional videos about its own apps to the studio's own TikTok account, @kharonteappdev.

The tool runs on the computer of the person who operates it, in a local web page that is only reachable from that computer. It is a single-user tool: there is no hosted service, no sign-up, and no other people use it.

How it uses TikTok

The tool uses TikTok Login Kit and the Content Posting API with the scopes user.info.basic, video.upload and video.publish.

The operator connects only their own TikTok account. Before every post the tool reads the account's creator information from TikTok and shows it, selects a video file stored on the operator's own computer, lets the operator choose the privacy level (there is no default selection), edit the caption and set comment, Duet and Stitch permissions, and asks for explicit confirmation of that exact post. Nothing is ever sent without that confirmation.

The tool can also send a video to the operator's TikTok inbox as a draft, so that publication is completed in the TikTok app.

What it does not do

  • It does not post automatically, on a schedule, or without the operator's confirmation of each individual post.
  • It does not read, collect or analyse other users' TikTok data.
  • It does not manage accounts for third parties and cannot be used by other people.
  • It does not automate browsing, following, liking, commenting or any other engagement.

Data and privacy

Everything the tool handles stays on the operator's own computer. See the Privacy Policy for details and the Terms of Service.
