# Kharonte Social Studio — website

Public pages (description, privacy policy, terms) for the TikTok developer app "Kharonte Social Studio",
a personal single-user tool of Kharonte Studio. Served by GitHub Pages at
`https://kharonte.dev/kharonte-social-studio/` (the account's user site has the custom domain `kharonte.dev`).

Static, no external requests, no cookies, no scripts. Contains no credentials and no application code.
